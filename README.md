# MintTap Web Manager

Canonical repository for the MintTap company website and app-launch web requirements.

- Company/product domain: `minttap.app`
- Platforms: Apple App Store / iOS and Google Play / Android
- Current phase: Foundation research before production website work
- Design knowledge dependency: `yhappcom/design-studio`

## Mission

Manage the web presence required to launch and operate MintTap apps. This includes company/product information, store-facing URLs, user support, privacy and legal surfaces, account-management web resources, app↔web domain association, advertising verification files when applicable, localization, accessibility, SEO/discoverability, operational freshness, and production QA.

This repository is not a substitute for Design Studio. Design Studio owns reusable design research; this repository applies that evidence to MintTap's real website and preserves MintTap-specific requirements and decisions.

## Working structure

- `STATUS.md` — current maturity, completed work, open risks and next research
- `AGENTS.md` — operating rules for current and future web-manager chats
- `research/` — source-grounded web operations and app-launch research
- `requirements/` — launch/site requirements derived from research
- `content/` — approved or draft MintTap website content
- `architecture/` — information architecture, routes and page-system decisions
- `legal/` — project-specific privacy/terms/compliance working material
- `ops/` — hosting, domain, verification, monitoring and release procedures
- `case-studies/` — later MintTap-specific design/website decisions where useful

## Operating principle

Study exists to improve real MintTap launch and website decisions. Reading alone is not completion. Important conclusions must distinguish official platform requirements, transferable synthesis, MintTap-specific judgment, unresolved items, dependencies and validation needs.
