## 106 material findings
- HTTP deprecation and sunset are distinct: deprecation communicates lifecycle status without changing behavior; sunset can signal expected unavailability. Neither proves a disconnected PWA received or completed migration.
- compatibility is a vector across reader, writer, schema/domain, sync protocol, API, trust/key, worker/cache, backup/import and bridge generations; semantic version distance alone is not a retirement oracle;
- retirement requires positive evidence for replacement, migration/restore, stale-outbox reconciliation, trust continuity, unsupported-state containment and communication, not disappearance of old clients from telemetry;
- ordinary runtime compatibility and recovery compatibility may have different lifetimes. A narrow current-code recovery reader/migrator can outlive a writable legacy API without retaining obsolete authority;
- `unsupported` should distinguish normal online operation from local read/export/recovery. A long-offline authoritative client can be denied unsafe sync while its records/outbox remain preserved for migration/reconciliation;
- security-driven accelerated retirement narrows authority first; it does not make legitimate local records disposable.

## Persistent guards added by 106
`deprecated ≠ non-operational`.  
`sunset announced ≠ every client received the announcement`.  
`deprecation header emitted ≠ migration completed`.  
`app version supported ≠ every dependent generation compatible`.  
`API responds 2xx ≠ operation semantics compatible`.  
`schema parses ≠ domain meaning preserved`.  
`zero observed old clients ≠ zero old clients`.  
`support window elapsed ≠ recovery obligation automatically disappears`.  
`legacy write disabled ≠ legacy data unreadable`.  
`normal sync retired ≠ recovery import must be retired simultaneously`.  
`reader retained ≠ obsolete authority retained`.  
`network reachable ≠ compatibility established`.  
`client authenticated ≠ protocol supported`.  
`update required ≠ local records invalid`.  
`unsupported for sync ≠ unsupported for local read/export/recovery`.  
`operation cannot be translated ≠ operation may be discarded`.  
`worker update available ≠ client updated`.  
`client updated ≠ local schema/protocol/trust migration complete`.  
`legacy protocol vulnerable ≠ legacy records malicious`.  
`credential revoked ≠ record ownership erased`.
