## 107 material findings
- recovery compatibility creates attack-surface debt: retained legacy readers, parsers, migrators, protocol translators and recovery endpoints remain security-critical code even when ordinary legacy runtime is retired;
- preserve the recovery obligation, not necessarily the vulnerable legacy implementation. A vulnerable parser can be removed while opaque artifacts are retained for a patched/replacement current-code converter;
- recovery bridges should minimize capability: read/convert rather than old-format write, current-authority initiation, bounded input, quarantine before publication, no old credential/trust revival and no blind outbox replay;
- externally supplied/restored backups remain untrusted input at the current boundary even when historically legitimate; provenance does not prove parser safety or current semantic validity;
- browser workers are not assumed to provide an application-controlled security sandbox. Exact Chromium/Safari/WebKit process isolation remains implementation/runtime evidence;
- compatibility should terminate at a current canonical representation rather than distributing legacy-mode branches throughout ordinary application logic;
- bridge debt enters release governance with an owner, supported generations, parser/dependency identity, isolation/resource limits, regression corpus, vulnerability state, retirement condition and fallback recovery route.

## Persistent guards added by 107
`legacy artifact historically legitimate ≠ artifact safe to parse with privileged current authority`.  
`artifact authenticated ≠ parser invulnerable`.  
`format recognized ≠ semantic migration safe`.  
`recovery compatibility retained ≠ legacy runtime authority retained`.  
`can decode old record ≠ may execute old operation`.  
`can migrate old schema ≠ may revive old credential`.  
`can inspect artifact ≠ may publish to live state`.  
`Web Worker used ≠ security sandbox proven`.  
`legacy parser retired ≠ legacy artifact must be discarded`.  
`old implementation removed ≠ recovery contract necessarily ended`.  
`bridge usage telemetry low ≠ no stranded artifacts exist`.
