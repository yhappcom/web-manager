Current time-based-media model:

`communication purpose → media class → information channels → information required for task/comprehension → synchronized equivalent(s) → player/control operability → product-evidence truth → localization/lifecycle → complete-media validation`

Retained judgments added by 057:
- captions, transcripts, audio description and media alternatives solve different channel-loss problems and are not interchangeable labels;
- WCAG media obligations depend on prerecorded/live and audio-only/video-only/synchronized classification plus conformance level;
- for prerecorded synchronized media, captions are Level A, while Level AA adds audio description where visual information is not already available in the main audio;
- a transcript is highly useful but transcript presence alone does not generally prove AA conformance for synchronized prerecorded video;
- accessible narration should be planned at script/storyboard time by verbalizing important controls, states and visual changes rather than relying on later remediation;
- media-content accessibility and media-player accessibility are separate obligations;
- automatic captions are a production aid, not sufficient evidence of caption semantic/temporal quality;
- app-demo video, captions, transcript/description and source app build form one versioned product-evidence unit;
- App Store preview acceptance/specifications and native-app accessibility declarations do not establish `minttap.app` WCAG conformance.

Reusable artifacts now include **Accessibility Evidence Contract** (051), **Semantic Accessibility Contract** (052), **Operability / Focus Contract** (053), **Accessible Transaction Contract** (054), **Accessible Application-State Contract** (055), **Adaptation / User-Preference Accessibility Contract** (056), and **Product-Demo Media Accessibility Contract** (057).
