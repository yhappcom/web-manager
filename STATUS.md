## 105 material findings
- controlled rollout is an exposure-management mechanism: exact-artifact evidence, canary/limited exposure, observability and a pre-defined breaker are distinct from build success;
- a PWA release can simultaneously contain different document, service-worker, cache, schema, trust, protocol and API generations; origin deployment does not establish installed-fleet convergence;
- recovery-critical changes include schema/data model, key/recovery hierarchy, worker/cache strategy, backup format, trust/protocol generation, sync/outbox semantics and API/support-horizon changes;
- recovery-critical rollout gates should cover exact artifact identity, forward migration, interruption/fault recovery, old/new backup restore, mixed-generation compatibility, degraded/recovery UX, rollout breaker evidence and post-rollback-state recovery;
- durable user/trust state should normally be treated as forward-moving unless an explicit tested lossless reverse migration exists; rollback commonly means code containment + compatibility bridge + forward repair rather than blind state reversal;
- unconditional `skipWaiting()+clients.claim()` is not a generic update best practice for an offline authoritative PWA; activation velocity is a compatibility/security decision;
- long-offline clients make rollout completion an evidence/policy problem: absence of old-client telemetry is not proof that no old authoritative clients remain.

## Persistent guards added by 105
`build passed ≠ rollout safe`.  
`artifact published ≠ installed fleet converged`.  
`canary healthy ≠ long-offline cohort compatible`.  
`rollback procedure exists ≠ user state can safely move backward`.  
`new worker installed ≠ new worker controlling every client`.  
`new worker active ≠ every open document built for that worker`.  
`code version N ≠ cache/schema/trust/API generation N`.  
`small code diff ≠ small recovery risk`.  
`feature flag off ≠ migrated local state rolled back`.  
`code rollback ≠ schema rollback ≠ key/trust rollback ≠ remote side-effect rollback`.  
`old binary restored ≠ old state representation restored`.  
`down migration implemented ≠ down migration lossless`.  
`faster activation ≠ safer recovery`.  
`security urgency ≠ permission to destroy unsynced local records`.  
`worker file removed from origin ≠ installed worker removed from clients`.  
`no old-client telemetry ≠ no old clients exist`.  
`connected fleet converged ≠ long-offline fleet recoverable`.
