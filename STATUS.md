## 129 checkpoint
- A recovery path earns continued existence by serving a current named recovery objective with current executable evidence; historical usefulness, documentation or redundancy count alone are insufficient.
- RTO, RPO and MTD are distinct consequence boundaries. RTO/RPO evidence does not by itself prove integrity, provenance, authorization or installed-PWA convergence.
- `resilience debt` is a local governance synthesis, not a NIST term: stale alternates, standing credentials, untested runbooks, obsolete compatibility paths and indefinite emergency bridges can increase attack/operational surface while contributing no proven recovery value.
- Recovery paths use explicit lifecycle states: CURRENT-PROVEN, CURRENT-MANUAL, STALE-REPROVE, REPLACE, RETIRE-CANDIDATE, RETIRE-IN-PROGRESS, RETIRED-VERIFIED and UNKNOWN.
- Keep/re-prove/replace/retire decisions follow current consequence/objective, distinct failure-mode coverage, dependency freshness, executable evidence and lifecycle cost/risk.
- Retirement removes runtime authority, credentials/routes/monitoring/runbook dependencies as applicable without erasing historical evidence or irreplaceable local data.
- Central origin RTO and central RPO do not prove offline installed-client recovery. Long-offline iPads remain separately governed by worker/client generation, local data, current trust/API and reconciliation state.
- Track C owns measured recovery timing/data-point evidence, integrity/provenance checks and post-retirement negative canaries.

## Persistent guards added by 129
`recovery path exists ≠ recovery objective met`.  
`restore succeeds eventually ≠ RTO met`.  
`latest backup exists ≠ RPO met`.  
`RTO met ≠ integrity/provenance restored`.  
`runbook retained ≠ recovery path executable`.  
`more alternate paths ≠ more usable resilience`.  
`path retained for safety ≠ path is safe to retain`.  
`zero production use ≠ recovery path unnecessary`.  
`retirement approved ≠ path retired`.  
`runtime path retired ≠ historical evidence deleted`.  
`origin RTO met ≠ installed-client recovery complete`.  
`central RPO met ≠ device-local unsynced data recovered`.  
`temporary bridge still works ≠ bridge should remain supported`.
