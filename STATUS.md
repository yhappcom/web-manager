### 036 — Navigation, wayfinding & findability as an operational system
`research/036-stage2-navigation-wayfinding-findability-operational-system.md`

**FOUNDATION/PRACTITIONER CHECKPOINT: PASS.**

Retained judgment:
- navigation has two jobs: **orientation + movement**;
- sitemap, hierarchy, URL space, navigation, breadcrumbs, search, direct entry and browser history are distinct layers;
- findability is multi-route across browse/search/contextual/direct/store/search-engine entry;
- labels are destination promises; optimize for predictability before visual brevity;
- global navigation should remain stable while app/support-local contexts can deepen;
- current location should be reinforced through title, heading, current state, app/section context and breadcrumbs where useful;
- breadcrumbs express meaningful hierarchy, not personal visit history and not necessarily raw URL structure;
- every critical destination must pass a direct-entry test because users may enter from stores/search/shared links;
- responsive navigation may change presentation/disclosure but should preserve the information model, labels and destinations;
- DOM/visual/focus/accessibility reading orders require separate validation;
- multiple navigation landmarks must be programmatically distinguishable;
- consistency means reusable mental models within coherent page sets, not pixel-identical universal headers;
- navigation failures are classified across coverage, label/scent, scope, placement, orientation, consistency, external entry, responsive, semantic/accessibility, retrieval, recovery and history/deep-link continuity;
- a critical-destination matrix now forms the project-level validation contract.

Primary/current evidence checked 2026-09-15:
- W3C WCAG 2.2 and current WAI Understanding guidance for Navigable, Page Titled, Focus Order, Headings/Labels, Consistent Navigation/Identification/Help, Resize Text and Reflow;
- WAI Menu Structure/Menus guidance and ARIA APG breadcrumb/navigation landmark patterns;
- Google Search Central breadcrumb documentation last updated 2026-09-08 and current mobile/desktop breadcrumb presentation guidance.
