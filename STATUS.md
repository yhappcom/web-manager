## 104 material findings
- traditional RPO/RTO remain useful business-impact concepts, but a device-authoritative offline PWA needs a vector: local durable-save, external-protection exposure, restore readiness, recovery duration, sync convergence, long-offline survivability and trust revalidation;
- freshness/data-loss exposure must be measured primarily against a logical committed authoritative frontier, not backup age or last-sync time;
- intentional offline operation is not itself an availability failure when required local tasks remain within contract;
- Google SRE-style error-budget governance transfers as a reliability/change-control principle, but ordinary percentage failure budgets must not be interpreted as permission to permanently lose irreplaceable user records;
- aggregate green metrics can hide long-offline/managed-device/old-format cohorts, so recovery evidence needs risk-relevant support-envelope segmentation;
- recovery-objective breaches should trigger bounded operational actions and truthful user states rather than silently weaken the recovery promise;
- no numeric RPO/RTO/SLO/budget threshold is selected without product impact, authority, destination, target-device and restore evidence.

## Persistent guards added by 104
`RPO defined ≠ every authoritative local change externally protected`.  
`RTO met ≠ restored state trustworthy/current/reconciled`.  
`service reachable ≠ user's authoritative offline data recoverable`.  
`backup age ≠ data-loss exposure`.  
`sync backlog ≠ backup backlog`.  
`zero sync backlog ≠ zero local recovery exposure`.  
`one recovery objective ≠ local durability + external protection + restore readiness + sync convergence + trust revalidation`.  
`error budget concept useful ≠ data-loss percentage acceptable`.  
`budget not exhausted ≠ individual user's irreplaceable data safe`.  
`aggregate reliability green ≠ tail recovery failure acceptable`.  
`offline ≠ app unavailable`.  
`online ≠ sync authorized`.  
`long offline supported ≠ indefinite stale-client compatibility guaranteed`.  
`wall-clock newer ≠ logically includes all earlier-looking authoritative changes`.  
`healthy average ≠ vulnerable cohort healthy`.  
`no telemetry received ≠ objective met`.
