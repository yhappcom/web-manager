## 118 material findings
- incident recovery should restore an explicitly acceptable current operating state, not mechanically recreate pre-incident privilege/trust/configuration;
- emergency privileges and emergency restrictions need different retirement semantics: privilege should generally expire/fail closed; containment denies may need explicit evidence-bearing relaxation rather than blind timeout;
- rollback is a forward transition from containment into a new trust baseline, not historical configuration rollback that can revive revoked credentials, retired APIs or old trust generations;
- emergency gates need stable identity, owner, scope, activation/expiry-review metadata, enforcement points, rollback prerequisites and closure evidence rather than one anonymous `incidentMode` switch;
- restore authority by capability: read/export, ordinary write, replay and destructive mutation can have different re-entry requirements;
- long-offline clients that missed both containment and rollback must still pass the current re-entry gate; central incident closure is not client remediation evidence;
- replay suppression needs an independent retirement gate because network/sync restoration does not prove compromise-era queued operations legitimate;
- rollback canaries must test negative invariants as well as availability: current clients succeeding does not prove stale/revoked clients remain denied;
- every incident-created account/token/feature flag/provider exception/temporary telemetry path needs retirement or explicit conversion into a deliberate permanent control.

## Persistent guards added by 118
`incident pressure ended ≠ pre-incident policy automatically safe`.  
`return to normal ≠ return to old trust generation`.  
`emergency control useful once ≠ standing privilege justified`.  
`one incident ≠ one reversible switch`.  
`policy rollback ≠ configuration snapshot rollback`.  
`normal service restored ≠ revoked credential revived`.  
`read safe ≠ write safe ≠ destructive operation safe`.  
`global emergency block removed ≠ every stale client re-authorized`.  
`credential freeze removed ≠ frozen credential valid again`.  
`replay suppression removed ≠ preserved outbox safe to flush`.  
`automatic expiry good for emergency privilege ≠ every containment deny should auto-expire`.  
`current client succeeds ≠ stale client remains denied`.  
`incident over ≠ incident-created authority gone`.  
`incident closed before device reconnects ≠ device skipped recovery`.
