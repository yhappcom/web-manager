## 117 material findings
- containment issuance, authoritative enforcement, observed client convergence, client remediation and compromise-era reconciliation are distinct evidence states;
- an offline PWA cannot be assumed to receive revocation/update policy while unreachable; the controllable security boundary is server/control-plane enforcement when it next requests remote authority;
- OAuth revocation can have distributed propagation delay, and revocation properties differ by token/system architecture; a successful revocation command is not fleet-wide enforcement proof;
- publishing a clean Service Worker/origin release does not prove an offline client fetched, activated or became controlled by it;
- fleet telemetry is positive evidence about observed clients, not proof that silent/unknown stale clients do not exist unless an independently authoritative fleet denominator exists;
- incident containment should prefer server-enforced invariants: reject compromised authority/generations, block unsafe stale mutations/replay and require explicit re-entry/recovery gates, while preserving local read/export/recovery where safe;
- revocation/convergence latency is plane-specific: auth, API, deployment, DNS/provider, trust and client-update paths need separate evidence.

## Persistent guards added by 117
