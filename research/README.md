## Strategic cross-track specialization — PWA
073 — **PWA Cross-Track Foundations: Service Workers, Offline, Install, Storage, Updates & Platform Reality — PASS.**

Track A + E owned integrated body; B/C/D consume it through handoffs. Covers AppCache historical lesson; PWA capability composition; secure-context/origin/scope trust; service-worker install/wait/activate/control/update semantics; cache-strategy failure modes; CacheStorage vs IndexedDB; quota/persistence/eviction; Safari/iPadOS vs Chromium/Android installation reality; safe update/data-preservation UX; navigation/performance interaction; background-capability boundaries; and EFB/LogMate-like offline/synchronization constraints.

Key contradiction guards:
- `PWA = one installability checklist` — false across current platforms;
- `service worker = offline cache` — incomplete;
- `skipWaiting = always better updates` — false;
- `cached offline = backed up` — false;
- `installed PWA = native-style background execution/sync` — unproven;
- `works on developer iPad = works on managed EFB` — false without target-device/policy evidence.

Current platform CHANGE WATCH: Safari 26/iOS/iPadOS 26 permits any site added to Home Screen to open as a web app by default, while manifest/service-worker capabilities remain enhancement layers. Chromium/Android install behavior is distinct. Target company EFB version/policy is OPEN.

Next PWA specialization block: **Data Durability & Synchronization Architecture Boundaries** — IndexedDB transaction/schema/migration model; local-first outbox/acknowledgement; retry/idempotency/conflict; backup/export/restore; long-offline recovery; suspension/background limits; web↔native transport boundaries; target EFB validation plan.
